Find the Mate in 1

Every position here was played in a real game, one move before it ended in mate. Find the move that mates. Each one you find adds to your streak; a miss starts it again.

Pick up a piece and play the move you think forces mate.

There may be more than one mate: any of them is right, and the answer names them all, each with what kind of mate it is and its escapes: 5/3/2 is 5 squares around the king, 3 of them not blocked by its own pieces, and 2 enemy pieces guarding those.

Positions

The filter applies to the file being played; the table of files below says what each file holds, so you can choose one.

Kinds of mate

Show: a position with such a mate. Hide: no position where such a mate is possible. Beside each kind, its mates in the file being played (the one the filter searches) and in all files.

Escapes

The escape profiles of the file being played, with their mates in it. Choose any number (Ctrl or ⌘ to choose several); a position is shown when one of its mates has one of them, with the kinds above. The table of files below shows every profile, file by file.

Files

Each file holds 1,000 positions. Each kind of mate, then each escape profile (in the order of their numbers, scroll sideways to see them all), has two columns: all its mates in the file, and those in positions with a single mate. What a whole filter finds in a file is known once the file is loaded. Click a column's name to sort by it, again to turn the order round, and a file's number to play it.
